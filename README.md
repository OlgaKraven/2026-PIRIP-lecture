# ПИРИП · подготовка к демонстрационному экзамену 2027

Интерактивный курс по дисциплине «Проектирование и разработка интерфейсов пользователя»:

- 5 лекций по 25 экранов — всего 125 экранов;
- 5 пошаговых лабораторных работ;
- связь материалов с заданиями 1, 2 и 3 КИМ 09.02.07-3-2027;
- сквозной тренировочный кейс «Конференции.РФ»;
- варианты PDF student и teacher;
- поиск, фильтр по заданию КИМ, темы, полноэкранный режим, прогресс и клавиатурная навигация.

## Локальный запуск

```bash
npm ci
npm run generate:qr
npm run dev -- --host 127.0.0.1 --port 4175
```

## Проверки

```bash
npm run lint
npm run typecheck
npm run test
npm run spellcheck
npm run build
npm run test:e2e
```

## PDF

```bash
npm run export:pdf
npm run export:pdf -- --lecture lecture-01-kim-and-mvp
npm run export:pdf -- --lecture lecture-01-kim-and-mvp --variant student
npm run export:pdf -- --lecture lecture-01-kim-and-mvp --variant teacher
npm run test:pdf
```

PDF сохраняются в `outputs/pdf/student` и `outputs/pdf/teacher`. Интерфейс сайта предоставляет только кнопку «Печать для преподавателя»; student-вариант используется как технический экспорт.

## GitHub Pages

Workflow `.github/workflows/pages.yml` собирает статический сайт с base `/2026-PIRIP-lecture/` и публикует `dist/client`.

## Важные границы

- «Конференции.РФ» — тренировочный пример из образца КИМ, а не гарантия окончательного задания оператора.
- 90 минут для лекции и 180 минут для лабораторной — методические рекомендации, не официальная академическая нагрузка.
- Содержимое папки Яндекс.Диска не перечисляется: URL используется только для QR-кода и перехода.
- Данные администратора `Conf2027 / Demo77` приведены в образце задания КИМ и используются только в учебном сценарии.
