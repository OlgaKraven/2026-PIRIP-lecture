Реестр и предметные исправления находятся в [SOURCES.md](../../SOURCES.md). Ссылки показаны на служебных и итоговых слайдах; карта переноса — в reports/migration-map.json.

КИМ и его приложение имеют приоритет перед учебными примерами. Методические рекомендации не подменяют обязательные требования. Исходные PDF/ZIP рассматриваются как источники данных и не публикуются в составе сайта. Правило оформления применяется по прямому запросу пользователя; данные доступа из него остаются приватными.
